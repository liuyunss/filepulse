# 文件脉搏（FilePulse）需求文档

## 项目概述

| 项目 | 说明 |
|------|------|
| 名称 | 文件脉搏（FilePulse） |
| 定位 | 跨平台文件分析筛选小工具 |
| 目标平台 | Windows、Mac、Linux |
| 技术栈 | Tauri（Rust 后端 + Web 前端） |

---

## 功能列表

### 1. 文件夹选择

- 拖拽文件夹到应用窗口
- 点击按钮选择文件夹
- 显示当前选中的文件夹路径

### 2. 筛选条件

每个条件前有复选框（勾选才生效），后有取反选项：

| 条件 | 输入 | 说明 |
|------|------|------|
| 大小筛选 | [大于/小于/等于] [数字] [MB/KB/GB] | 支持三种比较方式和三种单位 |
| 后缀筛选 | [后缀名] | 支持多个（逗号分隔）、通配符（*）、忽略大小写 |
| 修改日期 | [天数] 天内 | 筛选最近 N 天内修改的文件 |
| 空文件夹 | 无输入 | 筛选空文件夹 |

每个条件可勾选"取反"，实现反向筛选。

### 3. 文件列表

- 表格展示：文件名、大小、类型、修改时间、路径
- 支持排序（点击表头）
- 支持全选/反选
- 点击文件名可打开文件所在位置（系统资源管理器）

### 4. 文件删除

操作流程：
1. 点击 [预览] → 符合条件的文件高亮显示（红色背景）
2. 点击 [删除] → 弹出确认对话框，显示将删除的文件列表
3. 确认后执行删除

### 5. 文件夹解散

将嵌套文件夹中的文件提到上层，清理空文件夹。

**保留级别：**

| 级别 | 说明 | 示例 |
|------|------|------|
| 0 级 | 全部文件到根目录 | 所有文件平铺 |
| 1 级 | 保留1层文件夹，内部只有文件 | 文件往上找1层父文件夹 |
| 2 级 | 保留2层文件夹 | 文件往上找2层父文件夹 |
| 3 级 | 保留3层文件夹 | 以此类推 |

**操作流程：**
1. 选择保留级别 [0/1/2/3]
2. 点击 [预览解散] → 显示原始结构和解散后结构对比（相对路径）
3. 显示将删除的空文件夹列表
4. 点击 [执行解散] → 弹出确认对话框
5. 确认后执行移动和删除

**预览示例：**
```
原始结构：
📁 测试文件夹/
├── 📁 文档/
│   └── 📁 子文件夹/
│       └── 📄 笔记.txt
└── 📁 视频/
    └── 📄 电影.mp4

解散后（保留1级）：
📁 测试文件夹/
├── 📁 文档/
│   └── 📄 笔记.txt      ← 从子文件夹提到文档
└── 📁 视频/
    └── 📄 电影.mp4

将删除的空文件夹：子文件夹
```

### 6. 规则保存

保存筛选条件组合，下次直接执行。

**操作：**
- [保存当前条件为规则] → 输入规则名称，保存到本地
- [执行选中规则] → 加载规则的筛选条件并执行扫描
- [删除规则] → 删除选中的规则

**存储位置：**
- Windows: `%APPDATA%/FilePulse/rules.json`
- Mac: `~/Library/Application Support/FilePulse/rules.json`
- Linux: `~/.config/FilePulse/rules.json`

**规则格式（JSON）：**
```json
{
  "name": "清理小于1MB文件",
  "conditions": {
    "size": {"op": "less_than", "value": 1, "unit": "MB"},
    "size_negate": false,
    "extension": "",
    "extension_negate": false,
    "days": 0,
    "days_negate": false,
    "empty_folder": false,
    "empty_folder_negate": false
  }
}
```

## 界面布局

```
┌─────────────────────────────────────────┐
│  📁 选择文件夹 [拖入或点击选择]          │
│  当前路径：/Users/xxx/Documents         │
├─────────────────────────────────────────┤
│  ☐ [大于▼] [10] [MB▼]        ☐ 取反   │
│  ☐ 后缀等于 [.mp4,.avi]      ☐ 取反   │
│  ☐ 修改日期在 [7] 天内        ☐ 取反   │
│  ☐ 空文件夹                   ☐ 取反   │
├─────────────────────────────────────────┤
│  ☑ 文件名     大小    类型   修改时间   │
│  ☑ 文件1.txt  2MB    txt    2024-01-01 │
│  ☐ 文件2.mp4  1GB    mp4    2024-01-02 │
│  ...                                    │
├─────────────────────────────────────────┤
│  [扫描]  [预览]  [删除]     [高级 ▼]   │
└─────────────────────────────────────────┘

高级面板（默认收起）：
┌─────────────────────────────────────────┐
│  解散文件夹 - 保留 [1▼] 级              │
│  [预览解散]  [执行解散]                  │
│                                         │
│  已保存的规则：                          │
│  ☐ 清理小于1MB文件                      │
│  ☐ 删除所有.mp4                         │
│  [执行选中规则] [保存当前条件] [删除规则] │
└─────────────────────────────────────────┘
```

## 视觉风格

- 简洁朴素，不要花哨
- 浅色主题
- 纯 CSS，不用任何框架
- 字体用系统字体
- 颜色：浅灰背景，蓝色按钮
- 高级面板折叠，默认收起
