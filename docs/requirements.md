# 文件脉搏（FilePulse）需求文档

## 项目概述

| 项目 | 说明 |
|------|------|
| 名称 | 文件脉搏（FilePulse） |
| 定位 | 跨平台文件分析筛选小工具 |
| 目标平台 | Windows |
| 技术栈 | Flutter (Dart) |
| 当前分支 | dev |

---

## 测试记录 (2026-06-06)

### 1. 文件夹选择

| 测试项 | 方法 | 结果 | 备注 |
|--------|------|------|------|
| 点击浏览按钮 | FilePicker.getDirectoryPath() → 系统资源管理器选文件夹 | ✅ 通过 | 弹出原生 Windows 选择框 |
| 拖入文件夹 | desktop_drop DropTarget 监听 OS 拖放事件 | ✅ 通过 | 拖入时蓝色高亮，释放后扫描 |
| 显示当前路径 | 顶栏右侧显示路径 | ✅ 通过 | 超长路径自动省略 |

### 2. 筛选条件

| 条件 | 输入 | 结果 | 备注 |
|------|------|------|------|
| 名称筛选 | 勾选→选择[包含/前缀/后缀]→输入关键词→可选取反 | ✅ 通过 | 不区分大小写 |
| 后缀筛选 | 勾选→输入 .log → 可选取反 | ✅ 通过 | 逗号分隔多个后缀 |
| 大小筛选 | 勾选→选择[>/</=]→输入数字→选择[KB/MB/GB]→可选取反 | ✅ 通过 | |
| 日期筛选 | 勾选→选择[最近/早于]→输入数字→选择[时/天/月]→可选取反 | ✅ 通过 | |
| 空文件夹筛选 | 勾选→可选取反 | ✅ 通过 | 检查同目录文件是否全部0KB |
| 筛选实时生效 | 预览模式下修改条件自动刷新 | ✅ 通过 | 普通模式下不改动显示 |

## 已知问题

- 输入文件夹路径弹窗（Dialog）用户体验不如原生资源管理器，目前已改用 FilePicker 原生选择框
- 解散文件夹：空文件夹清理功能尚未实现，仅移动文件
- 暗色主题未适配
