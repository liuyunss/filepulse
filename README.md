# 文件脉搏（FilePulse）

跨平台文件分析筛选工具

## 功能

- 📁 拖入/选择文件夹
- 🔍 按大小筛选（大于/小于 X MB）
- 🏷️ 按后缀筛选（支持正则）
- 🗑️ 空文件夹检测
- 📂 文件解散（子文件提到根目录）
- 🗃️ 文件删除

## 技术栈

- **Tauri**（Rust + Web 前端）
- 目标平台：Windows、Mac、Linux

## 原型

`prototype/index.html` - HTML 原型，可直接浏览器打开
